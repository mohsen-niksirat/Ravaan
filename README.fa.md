## قابلیت‌های کلیدی

- ⚡ **اصلاح خودکار زبان اشتباه کیبورد (Auto-Fix):** تبدیل فوری کلماتی که با زبان اشتباه تایپ شده‌اند (مانند تبدیل خودکار `sghl` به `سلام`) به محض فشردن فاصله یا علائم نگارشی.
- ✍️ **اصلاح نگارش فارسی و نیم‌فاصله خودکار (ZWNJ):** تبدیل «ي» و «ك» عربی به «ی» و «ک» استاندارد فارسی و درج هوشمند نیم‌فاصله برای پیشوندهای «می/نمی» و پسوندهای «ها/تر/ترین/مند/شناس».
- 🔤 **تایپ فینگلیش به فارسی:** تبدیل نگارش آوایی لاتین به فارسی استاندارد (`salam` $\to$ `سلام`، `khosh amadid` $\to$ `خوش آمدید`) با اتکا به واژه‌نامه ۱۶۲ هزار کلمه‌ای معتبر.
- 🚀 **متن‌های آماده و جانشینی سریع (Snippets):** تعریف کلمات اختصاری مانند `;em` برای درج فوری نشانی ایمیل یا `;jdate` برای درج تاریخ روز هجری شمسی.
- 🧮 **ماشین‌حساب درون‌خطی:** محاسبه سریع فرمول‌های ریاضی حین تایپ بدون نیاز به باز کردن ماشین‌حساب (مانند تایپ `125*8=` $\to$ `1000`).
- 🛡️ **حفظ کامل حریم خصوصی (Zero Telemetry):** بافر چرخشی موقت در رم (حداکثر ۳۲ حرف)، بدون هیچ‌گونه ضبط کلیدها روی دیسک و بدون کوچک‌ترین ارتباط شبکه خروجی.
- 📦 **روش‌های متنوع نصب و به‌روزرسانی:** امکان نصب آسان از طریق **Winget**، **Scoop**، **Chocolatey**، بسته نصبی Inno Setup یا نسخه پرتابل.

## روش‌های نصب و راه‌اندازی

### ۱. نصب از طریق ابزارهای مدیریت بسته ویندوز

#### وینگت (Winget - پیش‌فرض ویندوز ۱۱ و ۱۰)
```powershell
winget install MohsenNiksirat.Ravaan
```

#### اسکوپ (Scoop)
```powershell
scoop install https://raw.githubusercontent.com/mohsen-niksirat/Ravaan/main/packaging/scoop/ravaan.json
```

#### چاکلیتی (Chocolatey)
```powershell
choco install ravaan
```

---

### ۲. بسته نصبی ویندوز (`Ravaan-Setup-1.0.0.exe`)
فایل نصبی را از بخش [انتشار نسخه‌ها در گیت‌هاب](https://github.com/mohsen-niksirat/Ravaan/releases/latest) دریافت کنید.
- **نصب بدون نیاز به دسترسی Administrator:** برنامه در مسیر کاربر نصب شده و نیازی به تاییدیه UAC ندارد.
- **حفظ داده‌ها هنگام به‌روزرسانی:** واژه‌نامه شخصی، تنظیمات و اسنیپت‌های شما در مسیر `%APPDATA%\Ravaan` در تمام نسخه‌ها محفوظ می‌ماند.
- **پاک‌سازی هوشمند هنگام حذف:** در هنگام حذف برنامه، از شما پرسیده می‌شود که آیا مایل به حذف داده‌های محلی هستید یا خیر (با دکمه پیش‌فرض امن «خیر»).
- *نکته درباره پیام SmartScreen:* در صورتی که با پیام آبی‌رنگ ویندوز دیفندر مواجه شدید، به [راهنمای عبور از اسمارت‌اسکرین](docs/SMARTSCREEN.md) مراجعه فرمایید.

---

### ۳. نسخه پرتابل و بدون نیاز به نصب (`Ravaan-Portable-1.0.0.zip`)
- بسته فشرده شامل فایل اجرایی `Ravaan.exe` و مستندات.
- بدون نیاز به نصب؛ کافی است آن را در هر پوشه‌ای یا روی فلش‌مموری استخراج کرده و اجرا کنید.

---

### ۴. اجرای مستقیم از سورس کد (برای برنامه‌نویسان)
```powershell
git clone https://github.com/mohsen-niksirat/Ravaan.git
cd Ravaan
pip install -e .[dev]
python -m ravan
```

## کلیدهای میانبر پرکاربرد

| میانبر | عملکرد | توضیحات |
| :--- | :--- | :--- |
| `Space` یا علائم | **اصلاح خودکار (Auto-Fix)** | اصلاح خودکار چیدمان یا اشتباه تایپی در انتهای کلمه |
| `Backspace` (< ۴ ثانیه) | **بازگردانی سریع (Undo)** | بازگردانی فوری کلمه اصلاح‌شده به متن اصلی تایپ‌شده |
| `Ctrl+Shift+Z` | **بازگردانی سراسری** | لغو آخرین تبدیل چیدمان یا تصحیح متن |
| `F12` | **تغییر دستی چیدمان** | تبدیل متن انتخاب‌شده یا آخرین کلمه بین فارسی و انگلیسی |
| `Shift+Space` | **درج دستی نیم‌فاصله** | درج نیم‌فاصله استاندارد (ZWNJ) |
| `Alt+V` | **تاریخچه کلیپ‌بورد** | باز کردن پاپ‌آپ تاریخچه کلیپ‌بورد در محل نشانگر |
| `Alt+S` | **آمار سریع متن** | نمایش تعداد کلمات، زمان مطالعه و درصد کلمات فارسی/انگلیسی |
| `Ctrl+F12` | **نرمال‌ساز متن فارسی** | تصحیح «ي» و «ك» و پاک‌سازی علائم در متن انتخاب‌شده |
| `Shift+F12` | **تغییر حالت حروف لاتین** | تغییر چرخشی بین حروف کوچک، بزرگ و Title Case |
| `Alt+Shift+F` | **تغییر حالت فینگلیش** | فعال یا غیرفعال کردن حالت تایپ فینگلیش به فارسی |

## سناریوهای نمایشی و دمو
برای مشاهده تصاویر و شبیه‌سازی‌های محیط برنامه در شرایط گوناگون به سند [راهنمای سناریوهای نمایشی و دمو](docs/DEMO.md) مراجعه فرمایید:
- **سناریو ۱:** اصلاح خودکار چیدمان اشتباه کیبورد (`sghl` $\to$ `سلام`)
- **سناریو ۲:** درج خودکار نیم‌فاصله نگارشی (`می روم` $\to$ `می‌روم`)
- **سناریو ۳:** گسترش متن‌های از پیش آماده (`;em` $\to$ `user@example.com` و عبارات منظم نظیر `re:;d(\d+)` $\to$ `گزارش روز $1`)
- **سناریو ۴:** تبدیل فینگلیش به فارسی با انتخاب از فهرست پیشنهادات
- **سناریو ۵:** محاسبات ریاضی درون‌خطی (`125*8=` $\to$ `1000`)
- **سناریو ۶:** سازوکار امنیتی و عدم ذخیره کلیدها

## امنیت و حریم خصوصی

امنیت و حریم خصوصی اولویت اول و تغییرناپذیر در معماری روان است:
- **عدم ثبت کلیدها:** نویسه‌ها تنها در حافظه موقت RAM در یک بافر چرخشی کوچک (حداکثر ۳۲ نویسه) برای تشخیص کلمه جاری قرار می‌گیرند و با فاصله یا تغییر پنجره کاملاً محو می‌شوند.
- **عدم ارسال اطلاعات (Zero Telemetry):** برنامه هیچ اتصال خروجی پنهانی به اینترنت برقرار نمی‌کند.
- **ذخیره‌سازی کاملاً محلی:** تمام اطلاعات شما در پوشه `%APPDATA%\Ravaan` در رایانه خودتان نگهداری می‌شود.
- **راهنمای بررسی مستقل:** برای آموزش نحوه اعتبارسنجی شبکه و دیسک با ابزارهای Process Monitor و Resource Monitor به [پرسش‌های متداول امنیت و شفافیت](docs/SECURITY_FAQ.md) مراجعه نمایید.

## معماری و ساختار پروژه

```text
ravan/
  ├── core/       # موتور واژگان (تیرای ۱۶۲ هزار کلمه)، چیدمان، فینگلیش، نیم‌فاصله و اسنیپت‌ها
  ├── data/       # دادگان فرهنگ لغت فارسی، کاتالوگ‌های زبان (en.json و fa.json)، آیکون‌ها
  ├── platform/   # قلاب‌های سطح پایین ویندوز (WH_KEYBOARD_LL)، تزریق کلید، رهگیری کرت و DPAPI
  └── ui/         # رابط‌های مدرن Tkinter، سینی سیستم (Tray)، ویزارد راه‌اندازی و پنجره تنظیمات
```
